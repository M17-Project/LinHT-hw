# LinHT-hw

**Open-source, Linux-based, SDR handheld transceiver**

[![CC BY-NC-SA 4.0][cc-by-nc-sa-shield]][cc-by-nc-sa]
![GitHub Actions](https://github.com/M17-Project/LinHT-hw/actions/workflows/main.yml/badge.svg)
[![Docs](https://img.shields.io/badge/docs-GitHub%20Pages-blue)](https://m17-project.github.io/LinHT-hw/)
![Status](https://img.shields.io/badge/status-active%20development-orange)

**LinHT** is an open-source handheld **software-defined radio (SDR) transceiver**,
built as a replacement mainboard for the **Retevis C62** radio. A Linux
System-on-Module runs the UI, DSP and radio control, and a direct-IQ RF front-end
gives true all-mode operation. There is no FPGA in the signal path.

It is the successor of the OpenHT project, developed by the
[**M17 community**](https://m17project.org) for radio amateurs, SDR experimenters
and developers. This repository contains the **hardware design files**.

> 📅 **October 2026 status**<br>
> Rev C boards are being tested. Rev C is the current revision on `main` and is
> not yet tagged or validated. Rev B results are in the
> [Rev B status report](https://m17project.org/2026/06/16/linht-rev-b-status-what-works-what-broke-and-why-rev-c-is-next/).

> ⚠️ **Important**<br>
> LinHT is an experimental, community-driven project, **not a consumer product**.

## At a glance

* **SoM:** CompuLab MCM-iMX93 (dual Cortex-A55, Cortex-M33, 2 GB LPDDR4, 32 GB eMMC)
* **RF:** Semtech SX1255 direct-IQ transceiver, up to 500 kHz bandwidth, 📌 **UHF only**
* **TX power:** about 4.5 W CW (measured on Rev B)
* **Software:** custom Yocto Linux with GNU Radio, SoapySDR, C/C++ and Python
* **Modes demonstrated so far:** ✅ FM, ✅ SSB, ✅ M17, ✅ TETRA (RX), 🧪 experimental 64-QAM

The full component list, revision history and RF details are on the
[LinHT wiki page](https://wiki.m17foundation.org/index.php?title=LinHT).
Changes between hardware revisions are listed in the [changelog](CHANGELOG.md).

## Building the hardware

LinHT cannot be bought yet. To build one you need to have the PCB made, source
and assemble the components, and move these parts over from a **Retevis C62**
donor radio: enclosure, display, keypad, battery, side-button PCB, SMA connector,
audio jacks, rotary encoder, springs and mechanical hardware.

The repository holds the KiCad 10.0 project. Gerbers, BOM, pick-and-place files,
schematics and 3D models are generated by GitHub Actions and published on
[GitHub Pages](https://m17-project.github.io/LinHT-hw/). They follow `main`, so
they currently show the unvalidated Rev C design. Use the `revA` and `revB` Git
tags for earlier revisions.

An older, Rev A focused build write-up:
[LinHT Open SDR Handheld For Radio Amateurs](https://uart.cz/2811/linht-open-sdr-handheld-for-radio-amateurs/)

## FAQ – Frequently Asked Questions

❓ **Is it suitable for everyday use?** Not yet. Expect no polished UI, no
certification and no warranty. It suits developers and experimenters comfortable
with Linux and hardware debugging.

❓ **Does it support VHF?** No. The current revisions are UHF-only, and VHF is not
planned for now.

❓ **Is it legal to transmit with?** LinHT is not certified. It is intended for
amateur radio, experimental licenses and lab use, and the builder and operator
are responsible for following local regulations.
